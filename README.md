# @dietdev/synth

Синтез звуковых эффектов для браузерных игр по компактным пресетам и пул их
проигрывания. Без зависимостей, ES-модуль, работает в браузере и в Node.

- **Пресет** — обычный объект с параметрами в естественных единицах: герцы,
  миллисекунды, октавы в секунду. Сотни байт вместо килобайт WAV.
- **Рендер** — чистая функция: пресет + сид → сэмплы → WAV data URL. Один сид —
  один и тот же звук при каждой загрузке; другой сид — вариант того же звука.
- **Два вида голосов:**
  - **тональный** — генератор, огибающая, толчки с разбросом, модуляция громкости
    и тона, фильтры в герцах;
  - **классический** — цикл sfxr (jsfxr) шаг в шаг, но в естественных единицах:
    копии звуков sfxr совпадают с оригиналом сэмпл в сэмпл.
- **`SfxPlayer`** — пул `Audio` на звук: перебор экземпляров по кругу,
  выключение звука и громкость колбэками.

## Установка

```bash
npm i @dietdev/synth
```

Нужна Node ≥ 18 или любой современный браузер; зависимостей нет.

Или локальной папкой: `"@dietdev/synth": "file:../synth"` в `dependencies`.
Из npm приходит уже собранный `dist`, а при установке из git его собирает
скрипт `prepare`. После правок исходников локальной копии пересоберите её
вручную — `npm run build` в папке пакета: при ссылке на папку `prepare` сам не
запускается, и потребитель видит старый `dist`.

`dist` собран под ES2022. Для старых браузеров (Safari 12 и т. п.) его
транспилирует сборщик потребителя — например, `@vitejs/plugin-legacy`.

## Быстрый старт

```ts
import { SfxPlayer, renderVariants, toWav, type Preset } from "@dietdev/synth";

// Короткий щелчок кнопки: синус с быстрым спадом тона и громкости
const CLICK: Preset = {
  ms: 60,
  peak: 0.5,
  voices: [{ wave: "sine", hz: 900, toHz: 400, env: { a: 1, d: 59, exp: true } }],
};

const sfx = new SfxPlayer({ isMuted: () => false, volume: () => 1 });

// Один вариант (тон без шума — сиды не нужны), 4 экземпляра Audio
sfx.add("click", 4, renderVariants(CLICK, [1]).map((s) => toWav(s)));
sfx.init();

button.addEventListener("click", () => sfx.play("click"));
```

## Как это устроено

```
Preset ──render(preset, seed)──► Float32Array ──toWav()──► "data:audio/wav;base64,…"
   │                                                               │
   └─renderVariants(preset, seeds): общий коэффициент громкости    └─► SfxPlayer.add(key, count, urls)
```

1. Каждый голос пресета рендерится в свой буфер длиной `ms`.
2. Голоса складываются.
3. На сумму действуют общий ФНЧ (`lp`, `lpPasses`) и общий вход/выход (`fade`).
4. `renderVariants` приводит пик самого громкого варианта к `peak` одним
   коэффициентом на все варианты.
5. `toWav` кодирует в 16-битный моно WAV 44 100 Гц, зажимая значения в ±1.

Звук считается один раз, обычно при старте игры, а проигрывается готовым
`Audio` — как у jsfxr, только по своим пресетам.

## Пресет

```ts
type Preset = {
  ms: number;                         // длина звука, мс
  voices: (Voice | Classic)[];        // голоса, складываются
  fade?: { in: number; out: number }; // линейный вход и выход всего звука, мс
  lp?: number;                        // ФНЧ на сумме голосов, Гц
  lpPasses?: number;                  // сколько раз пройти этот ФНЧ (по умолчанию 1)
  peak?: number;                      // пик самого громкого варианта после нормализации
};
```

- **`ms`.** Длина в сэмплах — `Math.round(ms × rate / 1000)`, одинаковая у всех
  вариантов. Голос, который кончился раньше, дальше молчит.
- **`fade`.** Вход — `i / F`, выход — `(n − i) / F`. При одинаковых `in` и `out`
  выход одного клипа и вход следующего, запущенного за `out` мс до конца, в
  сумме дают ровно 1 (см. [перезапуск](#зацикленный-звук-перезапуском)).
- **`lp` + `lpPasses`.** Однополюсный ФНЧ, 6 дБ на октаву за проход: два прохода —
  12 дБ, три — 18.
- **`peak`.** Работает только в `renderVariants`; `render` отдаёт сырой уровень.
  Без `peak` нормализации нет — уровень как есть (так ведут себя копии jsfxr).
  Значения за ±1 не портят WAV — `toWav` их зажимает, — но это слышимый клиппинг:
  при сложении громких голосов задавайте `peak`.

## Тональный голос

```ts
type Voice = {
  wave: "sine" | "saw" | "square" | "triangle" | "noise";
  hz?: number;      // частота, Гц (по умолчанию 440)
  toHz?: number;    // частота к концу звука: тон меняется линейно за ms пресета
  duty?: number;    // скважность квадрата 0..1 — доля «верха» (по умолчанию 0,5)
  noise?: number;   // добавка белого шума к тону: тон + noise·шум
  gain?: number;    // громкость голоса (по умолчанию 1)
  env?: Env;        // огибающая; без неё голос звучит всю длину на полной громкости
  pulses?: Pulses;  // голос — поезд толчков (см. ниже)
  am?: Lfo;         // модуляция громкости
  fm?: Lfo;         // модуляция тона
  lp?: number;      // ФНЧ голоса, Гц
  hp?: number;      // ФВЧ голоса, Гц
};
```

### Генераторы

| `wave` | Форма | Размах |
|---|---|---|
| `sine` | синус | ±1 |
| `saw` | пила вверх | ±1 |
| `square` | квадрат со скважностью `duty` | ±1 |
| `triangle` | треугольник | ±1 |
| `noise` | белый шум из ГПСЧ сида | ±1 |

`noise` — **добавка**: при `noise: 0.3` тон остаётся на полной громкости, а
сверху ложится шум ×0,3. Так звучит «грязный» тон: удар поршня, хрип мотора.

### Огибающая `Env`

```ts
type Env = { a?: number; h?: number; d?: number; exp?: boolean }; // мс
```

- `a` — линейная атака от 0 до 1.
- `h` — удержание на 1. **По умолчанию заполняет всё, что осталось** до спада в
  конце звука: `ms − a − d`.
- `d` — спад до 0: линейный или, при `exp: true`, экспонента `e^(−5k)` (к концу
  спада ≈ −43 дБ, затем тишина).
- После `a + h + d` голос молчит.

Пример: `{ a: 1, d: 119, exp: true }` у пресета на 120 мс — удар без удержания.

### Толчки `Pulses`

То, чего нет в jsfxr и ZzFX: громкость пульсирует отдельными толчками с
разбросом. Так получаются поршневые моторы, трещотки, дребезг, очереди.

```ts
type Pulses = {
  rate: number;       // толчков в секунду
  jitter?: number;    // разброс интервала, доля: интервал × (1 ± jitter)
  ampJitter?: number; // разброс громкости толчка, доля: 1 ± ampJitter
  decay: number;      // постоянная спада толчка, мс: e^(−t / decay)
  len?: number;       // длина толчка, мс (по умолчанию 6 × decay)
};
```

- Первый толчок — в момент 0, следующие — через `(1 / rate) × (1 + jitter·u)`,
  где `u` случайно в [−1, 1] из сида.
- Внутри толчка тон `hz` начинается с фазы 0 (каждый толчок — новый «удар») и
  может нести `noise`.
- Толчки складываются, если перекрываются.
- `toHz` и `fm` на голос с толчками **не действуют**: тон внутри толчка
  постоянный. `env`, `am`, `gain`, `lp`, `hp` действуют на весь поезд.
- `rate ≤ 0` — тишина. Шаг не меньше сэмпла, поэтому `jitter ≥ 1` не пускает
  толчки назад.

### Модуляция `Lfo`

```ts
type Lfo = { hz: number; depth: number };
```

- `am` — множитель громкости `1 − depth + depth·sin(2π·hz·t)`: при `depth: 0.3`
  громкость гуляет от 0,4 до 1.
- `fm` — множитель частоты `1 + depth·sin(2π·hz·t)`: при `depth: 0.02` тон гуляет
  на ±2 % (вибрато).

### Фильтры голоса

`lp` и `hp` — однополюсные (6 дБ на октаву), частота среза в герцах. Действуют
после огибающей и `am`. Для крутизны используйте общий `lp` пресета с
`lpPasses`.

### Сид и порядок голосов

Все голоса пресета берут случайные числа из **одного** ГПСЧ по очереди. Поэтому
перестановка голосов или добавление голоса с шумом меняет шум остальных — звук
с тем же сидом станет другим.

## Классический голос

Повторяет цикл sfxr (jsfxr) шаг в шаг: суперсэмплинг ×8, целочисленный период
тона, его собственные формы волн и фильтры. Нужен, чтобы перенести звуки sfxr
без потерь, а ещё он умеет то, чего нет у тонального голоса: скачок тона,
повтор, резонансный фильтр, фазер. Параметры — в естественных единицах.

```ts
type Classic = {
  kind: "classic";
  wave: "square" | "saw" | "sine" | "noise";
  hz: number;                    // начальная частота, Гц
  minHz?: number;                // нижний предел тона, Гц
  stopAtMin?: boolean;           // дойдя до minHz, звук обрывается
  slide?: number;                // спад/подъём тона, октав в секунду (минус — вниз)
  accel?: number;                // ускорение спада, окт/с²
  vib?: { hz: number; depth: number }; // вибрато: период × (1 + depth·sin)
  jump?: { ms: number; ratio: number }; // через ms частота × ratio
  repeat?: number;               // каждые ms тон, спад, скачок и скважность — заново
  duty?: number;                 // порог «верха» квадрата 0..0,5 (по умолчанию 0,5)
  dutySlide?: number;            // сдвиг порога в секунду
  env: { a: number; h: number; d: number; punch?: number }; // мс
  lp?: { hz: number; slide?: number; res?: number }; // резонансный ФНЧ
  hp?: { hz: number; slide?: number };               // ФВЧ
  phaser?: { ms: number; slide?: number };           // фазер
  gain?: number;                 // множитель громкости (по умолчанию 1)
};
```

Отличия от тонального голоса — так устроен sfxr:

- **Формы волн.** Квадрат — ±0,5, а не ±1. Синус — параболическое приближение
  со своим тембром. Шум — **выборка-хранение**: 32 случайных значения на период
  тона, поэтому у шума есть высота (`hz`). Треугольника нет.
- **Огибающая обязательна и задаёт длину звука.** Атака `a` линейная; на
  удержании `h` громкость `1 + 2·(1 − t/h)·punch` — подъём в начале, к концу
  удержания 1; спад `d` линейный. После `a + h + d` (или на `minHz` при
  `stopAtMin`) голос обрывается. `ms` пресета должен это покрывать; точный
  момент обрыва даёт `classicEnd`.
- **Тон.** `slide` и `accel` меняют период тона мультипликативно каждый сэмпл,
  поэтому спад экспоненциальный. Без `minHz` нижний предел ≈ 3,5 Гц и обрыва нет.
- **`repeat`** перезапускает тон, спад, скачок и скважность, но не огибающую,
  фильтры, фазер и вибрато.
- **`lp`** — резонансный двухполюсный ФНЧ sfxr: `slide` сдвигает срез в
  октавах в секунду, `res` 0..1 — резонанс. Затухание резонанса считается один
  раз по начальной частоте. Коэффициент ограничен — срез не выше ≈ 5,6 кГц.
  Без `lp` тон идёт без ФНЧ.
- **`hp`** — ФВЧ sfxr; при любом включённом фильтре его коэффициент не меньше
  ≈ 0,56 Гц.
- **`phaser`** — подмешивание задержанной копии: `ms` — задержка (знак влияет
  только на её ход при `slide`), не больше ≈ 2,9 мс.
- **Уровень:** `0,125 × сумма 8 подсэмплов × огибающая × gain`. `gain`
  соответствует квадрату громкости sfxr.
- Коэффициенты считаются от `rate`, но сэмпл в сэмпл с jsfxr копия совпадает
  при 44 100 Гц.
- **Не округляйте** параметры перенесённых из sfxr звуков: период тона
  целочисленный, и округление даже до 8 значащих цифр может сдвинуть его на
  границе — у звука с повтором и скачком тона расхождение доходит до сотен
  разрядов.

Классический голос можно смешивать с тональными в одном пресете.

## Рендер и варианты

```ts
render(preset, seed, rate?)          // → Float32Array, сырой уровень
renderVariants(preset, seeds, rate?) // → Float32Array[], общая нормализация к peak
toWav(samples, rate?)                // → "data:audio/wav;base64,…"
```

- **Вариант = сид.** Разные сиды дают разный шум и разброс толчков при одних
  параметрах. Для тональных звуков без шума сиды одинаковы — хватит `[1]`.
- **Нормализация общая.** Коэффициент один на все варианты: если вариант 2 тише
  варианта 1, так и останется. Это сохраняет естественный разброс.
- **Детерминизм.** `render(p, 5)` всегда даёт одни и те же сэмплы — удобно для
  тестов и для того, чтобы звук не «плыл» между запусками.
- **Разные звуки одного ключа** — разные пресеты: рендерите каждый и
  складывайте URL в один список для `SfxPlayer.add`.

```ts
const urls = [presetA, presetB].flatMap((p) => renderVariants(p, [1, 2])).map((s) => toWav(s));
sfx.add("hit", 4, urls); // 2 пресета × 2 сида = 4 варианта, по 4 Audio на каждый
```

## SfxPlayer

```ts
const sfx = new SfxPlayer({
  isMuted: () => settings.muted, // читается при каждом play()
  volume: () => settings.volume, // 0..1, читается при каждом play()
  debug: import.meta.env.DEV,    // логировать неизвестный ключ
});
```

| Метод | Что делает |
|---|---|
| `add(key, count, urls)` | регистрирует звук: `count` экземпляров `Audio` на каждый URL |
| `init()` | создаёт `Audio` для зарегистрированных звуков порциями, по звуку раз в 50 мс |
| `initSound(key, count, urls)` | сразу создаёт `Audio` и **дописывает** варианты к ключу |
| `play(key)` | случайный вариант, внутри него — следующий экземпляр по кругу |

- **Пул — на вариант.** `add("engine", 10, [a, b, c])` создаёт 30 `Audio`.
- **Занятый экземпляр не перезапускается.** `play()` по ещё звучащему `Audio`
  ничего не делает, поэтому пул должен покрывать перекрытие: при длине звука
  `L` мс и вызовах раз в `P` мс нужно `count ≥ L / P` (с запасом на случайный
  выбор варианта).
- **Громкость** зажимается в 0..1; нечисловое значение даёт 1.
- **Ключ можно объявить заранее** пустым списком (`add(key, n, [])`) и
  дорендерить позже через `initSound` — до этого `play(key)` молчит. Так
  тяжёлый рендер не задерживает старт:

```ts
for (const [key, s] of Object.entries(SOUNDS)) sfx.add(key, s.count, []);
sfx.init();
for (const [key, s] of Object.entries(SOUNDS)) {
  setTimeout(() => sfx.initSound(key, s.count, renderVariants(s.preset, s.seeds).map((x) => toWav(x))), 0);
}
```

- Отказ автоплея до первого жеста пользователя глушится: `play()` не бросает.

## Рецепты

Все пресеты ниже — рабочие: их можно вставлять как есть и подкручивать.

### Щелчок интерфейса

```ts
const CLICK: Preset = {
  ms: 60,
  peak: 0.5,
  voices: [{ wave: "sine", hz: 900, toHz: 400, env: { a: 1, d: 59, exp: true } }],
};
```

### Монетка

Классический голос: квадрат и скачок тона вверх через 70 мс — «дзынь».

```ts
const COIN: Preset = {
  ms: 230,
  voices: [
    {
      kind: "classic",
      wave: "square",
      hz: 988,
      duty: 0.25,
      jump: { ms: 70, ratio: 1.335 },
      env: { a: 0, h: 60, d: 160, punch: 0.4 },
      gain: 0.3,
    },
  ],
};
```

### Взрыв

Шум с долгим экспоненциальным спадом под глухим фильтром плюс короткий низкий
удар.

```ts
const BOOM: Preset = {
  ms: 900,
  peak: 0.8,
  lp: 900,
  lpPasses: 2,
  voices: [
    { wave: "noise", gain: 1, env: { a: 2, d: 898, exp: true } },
    { wave: "sine", hz: 90, toHz: 30, gain: 0.8, env: { a: 1, d: 250, exp: true } },
  ],
};
```

### Выстрел

Слои: треск (шум выше 1,5 кГц), удар со спадом тона, «рявк» в середине спектра
и глухой хвост.

```ts
const SHOT: Preset = {
  ms: 380,
  peak: 0.6,
  voices: [
    { wave: "noise", gain: 0.5, hp: 1500, env: { d: 25, exp: true } },
    { wave: "sine", hz: 120, toHz: 55, gain: 0.9, env: { a: 1, d: 130, exp: true } },
    { wave: "noise", gain: 0.7, lp: 900, hp: 250, env: { a: 1, d: 80, exp: true } },
    { wave: "noise", gain: 0.35, lp: 350, env: { a: 3, d: 350, exp: true } },
  ],
};
```

### Поршневой мотор

Толчки 28 в секунду с разбросом интервала и громкости, внутри толчка — тон
80 Гц с шумом; под ними — ровный гул винта с медленным колыханием громкости.
Клип рассчитан на [перезапуск](#зацикленный-звук-перезапуском) раз в ~216 мс.

```ts
const ENGINE: Preset = {
  ms: 257,
  fade: { in: 40, out: 40 },
  lp: 500,
  lpPasses: 2,
  peak: 0.52,
  voices: [
    { wave: "sine", hz: 80, noise: 0.3, pulses: { rate: 28, jitter: 0.08, ampJitter: 0.2, decay: 16 } },
    { wave: "sine", hz: 75, gain: 0.25, am: { hz: 3, depth: 0.3 } },
  ],
};
// Три сида — три клипа с разным рисунком толчков
const urls = renderVariants(ENGINE, [1, 2, 3]).map((s) => toWav(s));
```

### «Пиу» лазера

## Зацикленный звук перезапуском

`SfxPlayer` проигрывает одноразовые клипы. Непрерывный звук (мотор, гул) — это
один и тот же клип, который игра перезапускает, пока звук нужен: например, раз в
200 мс, пока зажат газ.

Чтобы стыки не были слышны:

1. Узнайте реальный период перезапуска `P`. Если счётчик в игровом цикле
   сбрасывается в 0, период — первое кратное длине кадра больше заданного: при
   200 мс это 216 мс на 60 FPS, 233 мс на 30, 201 мс на 144.
2. Сделайте клип длиной `P + F`, где `F` — длина кроссфейда, и задайте
   `fade: { in: F, out: F }`. Тогда выход одного клипа совпадает со входом
   следующего, и громкость на стыке ровная.
3. Если период плавает, рассчитывайте на самый длинный: клип длиннее периода
   даёт небольшой подъём громкости на стыке, клип короче — провал, а провал
   слышнее.
4. Дайте 2–3 сида, чтобы соседние клипы различались рисунком, и пул
   `count ≥ (P + F) / P` на вариант.

## Советы по подбору

- **Ниже 60 Гц ноутбуки и телефоны почти не играют.** Удар на 30 Гц на хороших
  колонках слышен, на ноутбуке пропадёт. Держите основную энергию выше 60 Гц
  или дублируйте низ гармоникой.
- **Спад тона вниз за 100–300 мс звучит как «пиу» бластера.** Для тяжёлого
  удара — низкий старт и короткий, небольшой спад.
- **Одиночный шум похож на хлопок ладоней,** очередь таких — на аплодисменты.
  Шуму нужен фильтр и тело: тон под ним или низкий `lp`.
- **Длинный яркий шум без фильтра шуршит** — как трясущийся лист бумаги.
- **Сравнивайте громкость по RMS, а не по пику:** плотный звук при том же пике
  громче.
- **Слушайте «как в игре»:** звук, который играется 30 раз в секунду, звучит
  совсем не так, как одиночный. Смоделируйте реальный темп и пул.
- **Неровность оживляет.** Механически ровный повтор звучит электронно;
  `jitter` 0,05–0,1 и `ampJitter` 0,1–0,2 делают его живым.

## Производительность

- Тональные голоса — один проход на сэмпл: клип 257 мс из двух голосов
  рендерится за несколько миллисекунд.
- Классический голос считает 8 подсэмплов на сэмпл и заметно дороже: длинные
  (секунды) шумовые звуки — десятки миллисекунд.
- `toWav` — около миллисекунды на 10 000 сэмплов.
- Набор из пары десятков звуков рендерится за сотни миллисекунд. Не держите
  главный поток: объявляйте ключи пустыми и рендерьте по звуку в `setTimeout`
  (см. [SfxPlayer](#sfxplayer)).
- Экземпляры `Audio` одного варианта делят одну строку data URL — `count` не
  умножает память на строки.

## Справочник API

| Экспорт | Сигнатура | Назначение |
|---|---|---|
| `render` | `(preset: Preset, seed: number, rate = 44100) → Float32Array` | сырой рендер |
| `renderVariants` | `(preset: Preset, seeds: number[], rate = 44100) → Float32Array[]` | варианты с общей нормализацией к `peak` |
| `toWav` | `(samples: Float32Array, rate = 44100) → string` | WAV data URL, 16 бит, моно; значения за ±1 зажимаются |
| `SAMPLE_RATE` | `44100` | частота по умолчанию |
| `rng` | `(seed: number) → () => number` | детерминированный ГПСЧ (mulberry32), значения в [0, 1) |
| `lowpass` / `highpass` | `(s: Float32Array, hz: number, rate: number) → void` | однополюсные фильтры на месте |
| `classicEnd` | `(v: Classic, rate: number, max: number) → number` | сэмпл, на котором классический голос оборвётся |
| `SfxPlayer` | `new SfxPlayer(options?: SfxOptions)` | пул проигрывания |
| типы | `Preset`, `Voice`, `Classic`, `Env`, `Pulses`, `Lfo`, `Wave`, `SfxOptions` | |

## Разработка

Нужна Node ≥ 22.6: тесты запускают `.ts` напрямую (type
stripping). CI гоняет их на Node 24 при каждом push и PR.

```bash
npm install
npm run build      # tsc → dist
npm run typecheck
npm test           # node --test (type stripping), тесты в test/
```

В `test/reference/` лежат инструменты и эталоны для тестов: метрика сходства
звуков (спектр, ритм огибающей, громкость, неровность толчков), модель
проигрывания с пулом и пресеты классического голоса с отпечатками рендеров.

Выпуск: поднимите `version` в `package.json`, допишите `CHANGELOG.md` и
запушьте тег `v<версия>` — workflow `publish.yml` опубликует пакет в npm.
